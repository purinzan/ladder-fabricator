从 JSON 电路 AST 生成清晰的 PLC 梯形图。

一次验证，同一份源文件可生成三菱 MELSEC iQ-F 或基恩士 KEYENCE KV-X 风格的 SVG、高分辨率 PNG、梯级文本和连接结构 JSON。

1 个事实来源经过验证的电路 AST

快速开始

验证、检查、渲染。

需要 Python 3.10 或更高版本。PNG 使用可选的 CairoSVG 依赖。

git clone https://github.com/purinzan/ladder-fabricator.git
cd ladder-fabricator
python -m pip install ".[png]"

ladder-fabricator examples/basic.json --validate-only
ladder-fabricator rung-text examples/basic.json --comments
ladder-fabricator examples/basic.json -o basic.svg
ladder-fabricator examples/basic.json -o basic.png

当前支持

范围明确的梯形图词汇。

类别支持内容
触点常开、常闭、上升沿、下降沿
逻辑可嵌套 AND、OR、NOT，最外层 INV
比较字软元件之间的 =、<>、<、<=、>、>=
输出OUT、SET、RST/RES、PLS/DIFU、PLF/DIFD、PID、MOV

结构验证不等于 PLC 运行验证或机械安全认证。用于真实设备前必须在厂商官方环境中审查。
