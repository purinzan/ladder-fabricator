# GX Works3表示の測定基準

SVGの見た目は、三菱電機「GX Works3 Operating Manual」SH-081215ENG-AS（2026年1月）、
369ページの「Configuration of a ladder editor」に掲載されたラダー編集画面を基準にしています。

## 測定方法

公式PDFの該当ページを300dpiで描画し、ラダー編集領域を画素単位で調べました。
公式図は誌面へ縮小配置された画面例なので、色と部品比率は図から測定し、線幅はSVGを100%表示した時の
CSSピクセルへ正規化しています。GX Works3は表示倍率、文字の自動調整、列幅を変更できるため、
すべての設定で同じ画素配置になるという意味ではありません。

## 参照プロファイル

| 要素 | SVG値 | 公式図で確認した特徴 |
|---|---:|---|
| 配線・母線・接点・コイル | 1px、`#202020` | 同じ濃さの細い線。300dpi図では主線の暗色コアが約3px |
| 命令枠 | 1px、`#202020` | 角丸なしの矩形 |
| グリッド | 0.6px、`#c6c6c7`、1px/2px点線 | 白地に薄い点線 |
| 行コメント帯 | `#a2dfdf` | 青緑の帯。境界は`#4c925e` |
| デバイスコメント | `#2f8a48` | 緑文字 |
| 命令セル | 上`#f4f3f3`、中央`#d3d3d3`、下`#969796` | 命令名側だけが縦グラデーション |
| 1列 | 104px | 元のGX3解析側SVGと共通の列幅 |
| 1行 | 86px | コメントを読める大きさを保った行高 |
| 命令枠の高さ | 58px | SET/RST/PLSと複数オペランド命令で共通 |
| OUTコイル | 直径24pxの円 | 公式図の約1/4列幅という比率に合わせる |

SET、RST、PLSは命令名の灰色セルと対象デバイスの白いセルに分け、対象コメントを白いセル内へ表示します。
OUTは円形コイルとして表示します。線には`vector-effect="non-scaling-stroke"`を指定し、SVGを拡大縮小しても
ブラウザー上の線が不必要に太くならないようにしています。主線には`shape-rendering="crispEdges"`相当の
指定も加え、座標を0.5px補正しています。100%表示では、整数座標を中心にした1px線が隣接する
2画素へ半分ずつにじむ現象を避け、濃い1画素として描画します。
