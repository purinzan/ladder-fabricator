# Universal AI entry point

Before any ladder-circuit task in this repository:

1. Read `AGENTS.md`.
2. Read `README.md` in full.
3. Treat README’s “AST・命令リファレンス（正本）” as the only supported
   authoring vocabulary.
4. Follow README’s “AIの作成手順”.

Do not infer syntax from the project name or from PLC knowledge. Unsupported
instructions must be reported, not approximated.
