# gx3-ladder-export

GX Works3プロジェクトから、指定したラダー回路をSVGと論理構造として出力するためのツールです。

## 予定する範囲

- プログラム、デバイス、回路範囲を指定したラダーの抽出
- 接点・分岐・命令・デバイスコメントを含むSVG出力
- 回路要素、接続関係、出力ごとの条件式を扱える構造化JSON出力
- 元回路の位置情報と、未対応・解析不能・打切りなどの制約の保持

既存の gx3-cli-mcp から必要な処理を切り出す予定です。
現在はリポジトリの準備段階で、実装の移植はまだ行っていません。

## データの扱い

入力プロジェクト、展開済みデータ、生成したSVG・JSONなどの解析結果はローカルで扱い、
このリポジトリには登録しません。テストには合成データを使用します。

SVGは独自に再構成した表示であり、GX Works3の画面との完全一致を保証するものではありません。
論理構造は静的解析の結果であり、PLCの現在値や実行時動作を示すものではありません。
